服务对象

有节点就能接，用户多少都行

对外运营的服务商，和自建自用的个人，用的是同一套接入方式。

服务商

你出服务器和用户，平台出后台

把节点接进来就有独立后台：自己的识别码、自己的注册页、自己的用户池。 鉴权、流量、在线状态都由平台算好，你只管运营。

  • 多节点统一看板：在线、最后心跳、每台流量
  • 每个用户按天用量，超额或到期可一键踢下线
  • 终端用户自助注册 /join/{code}，不用手工开号
  • 你的用户和别人的用户互相看不见
适合 对外提供服务的团队 / 个人
个人

自己几台机器，也能管得清爽

自用或分享给朋友：一条命令装好节点，账号分开发，谁用了多少一目了然。 不用为了几台机器去维护一整套后台。

  • 节点装完即用，客户端扫码或导入链接
  • 朋友各自一个账号，停用立刻生效
  • 每台服务器、每个账号的流量都能查
  • 以后要对外运营，同一套直接扩
适合 自建自用 / 小范围分享

平台能力

接入之后，这四件事不用你写代码

01

接入节点：一条命令，配置按你的识别码生成

安装脚本从平台拉取模板，渲染端口、混淆密码、鉴权地址，生成证书并注册节点。 你不需要逐台改 YAML，也不用记每台机器装的是哪一版。

  • 模板统一维护，节点重装即生效
  • 自动生成证书并上报指纹，客户端可固定校验
  • systemd、防火墙、trafficStats 一起配好
节点侧写入的关键配置
auth:
  type: http
  http:
    url: 'https://auth.ipx.sarl/auth'
    insecure: false
trafficStats:
  listen: '0.0.0.0:8080'
  secret: 平台按节点生成
02

HTTP 鉴权：账号状态，节点侧实时生效

节点把每次连接交给平台的鉴权接口：账号是否启用、是否到期、流量是否超额， 平台说了算。停用之后，下一次连接就进不来，不用改节点配置。

  • 支持 uuid 直连、邮箱密码、连接令牌
  • 永远 200 + ok:false，符合 Hysteria 契约
  • 鉴权服务独立部署，面板维护不影响连接
节点 ↔ 平台
POST https://auth.ipx.sarl/auth
{"addr":"1.2.3.4:5678","auth":"<base64(uuid)>"}

→ {"ok":true,"id":"<uuid>"}
→ {"ok":false,"msg":"账号已停用，请联系服务商"}
→ {"ok":false,"msg":"账号已到期"}
03

服务器流量：在线、心跳、每台用量

平台按节点轮询 trafficStats，增量累加进你的后台。哪台在线、哪台掉线、 今天跑了多少，打开面板就能看到，不用逐台 SSH。

  • 在线 / 离线 / 最后心跳时间
  • 按天聚合，节点之间可以对比
  • 节点密钥由平台保存，不落在浏览器里

04

用户流量：谁用了多少，看得清也管得住

每个终端用户都有独立 uuid，平台按用户累计流量并按天归档。 用户自己在用户中心能看用量；你这边能看到全部，也能立刻停用、踢下线。

  • 用户中心：每个服务器用了多少、剩余多少
  • 后台：按运营商 / 节点 / 用户筛选
  • 踢人有队列与回执，不是发出去就不管

接入流程

从注册到第一个用户，四步

  1. 1

    注册服务商

    填名称、登录邮箱和密码，拿到自己的运营商识别码与后台。

  2. 2

    在节点上执行接入命令

    模板、证书、鉴权地址、trafficStats 一次配好，节点自动注册到你的后台。

  3. 3

    把注册页发给用户

    用户在 /join/{code} 自己注册，或用你的 10G 体验页链接开通。

  4. 4

    看流量、管用户

    服务器与用户用量自动汇总；到期、停用、超额，后台直接处理。

常见问题

接入前会问的几件事

还有别的，注册后在后台联系平台。

接入需要改节点上的什么？

基本不用手改。接入脚本会写好 auth.http.url、trafficStats、证书和 systemd 单元，只把运营商识别码传进去即可。已经有节点想接进来，也可以只改鉴权地址和 trafficStats 两段。

HTTP 鉴权稳定吗？面板维护会不会断？

鉴权由独立服务承担，和后台分开部署：后台升级、重启不影响节点鉴权。接口遵守 Hysteria 契约，任何情况都返回 200，体里用 ok 和 msg 说明结果。

流量是怎么统计的？

平台定时读取节点 trafficStats，按用户取增量并累计，同时保留按天归档。服务器维度和用户维度都能查；停用或超额可以进踢人队列。

支持哪些系统？

节点侧面向 Linux（systemd），amd64 / arm64 都可以。接入脚本会在节点上生成证书、写配置、注册并重启服务。

个人只有一两台机器，也能用吗？

可以。个人和服务商用同一套接入方式，区别只是规模：个人看自己的节点和账号，服务商多了用户注册页和多运营商隔离。

用户怎么来？有没有体验流量？

把你的注册页 /join/{code} 发给用户即可；平台还提供 10 GB 体验页，链接带上你的识别码，用户看到的就是你的入口：看体验页。

我的用户数据别人能看到吗？

不能。用户、节点、流量都挂在运营商识别码下，后台按租户隔离；平台侧只做运维管理。
